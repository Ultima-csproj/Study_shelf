# Исторический SQLite-адаптер

С 5 октября 2026 года активный workspace использует study-storage-postgres.

Здесь сохранены прежний study-storage-sqlite и SQLite HTTP-тесты как источник истории реализации. Они не входят в workspace и не запускаются текущими командами Cargo. Относительные зависимости архивного Cargo.toml отражают прежнее расположение; это не самостоятельно запускаемый пакет.

Существующий backend/data/study.sqlite3 не удаляется и автоматически не импортируется. Для новой модели используются отдельные PostgreSQL migrations и dev seed.
