# Демонстрационные учебные данные до этапа 11

Здесь сохранены старые массивы материалов, дисциплин, преподавателей и подборок. Они исключены из активного TypeScript проекта.

Файлы отражают прежнее расположение импортов и не являются запускаемым приложением. Активные дисциплины/подборки теперь используют PostgreSQL API и ссылки на текущую опубликованную редакцию Material.

Профиль и сохранения ещё локальные, до этапа auth. Старые source=mock ссылки не преобразуются в реальные Material IDs.
