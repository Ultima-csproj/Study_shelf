## Адаптивность и взаимодействия

- [Телефон](reference/qa/catalog-mobile.png): CSS viewport 390 × 844, снимок 375 × 811; scrollWidth = 375 <= innerWidth = 390, горизонтального переполнения нет.
- [Планшет](reference/qa/catalog-tablet.png): CSS viewport 1024 × 900, снимок 1009 × 887; scrollWidth = 1009 <= innerWidth = 1024, горизонтального переполнения нет. Панель слева, даты под заголовками.
- [Диалог фильтров](reference/qa/mobile-filters.png): открытие, применение и закрытие работают; Escape возвращает фокус на управляющую кнопку.
- Тема меняется в обе стороны, тёмная тема сохраняется после reload.
- Фильтр «Книга» даёт одну строку; снятие возвращает 28. Четвёртый курс показывает пустую выдачу. Поиск «нормальные формы» даёт одну лекцию, неизвестный запрос — пустое состояние; очистка восстанавливает список.
- Сортировка по старым датам меняет порядок. Страница 2 показывает 6–10 из 28; aria-current соответствует выбранной странице.
- Нажатие SQL добавляет фильтр тегов. Поиск преподавателя и фильтр года меняют выдачу; удаление восстанавливает результаты.
- Элементы имеют доступные названия, видимый фокус, настоящие checkbox/select, семантические landmarks и ссылку перехода к основному содержимому.
- Браузерные console errors/warnings: пустой список.
- npm run build и npm run lint: exit code 0, без предупреждений.

## Остаточные различия и ограничения

- **P3:** разница библиотечной пиктограммы бренда, мелких деталей сгенерированных обложек и отдельных микропромежутков. Использованию не мешает; новый дизайн-цикл не требуется.
- Данные демонстрационные, счётчики отражают эти данные. Шестая страница вместо условной седьмой — ожидаемое поведение.
- Исходник не содержит тёмную тему, мобильное состояние и пустую выдачу. Они реализованы в рамках утверждённого стиля и проверены отдельно.
- Открытие материалов, playback и другие экраны находятся за рамками этапа.
- Реальные сетевые ошибки не воспроизводятся: источник локальный. Компонент ошибки предусмотрен для будущего API.
