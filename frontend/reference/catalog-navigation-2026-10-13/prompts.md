# Catalog navigation concept prompts

Date: 2026-10-13.
Mode: built-in image_gen, two new UI mockups with the existing catalog screenshot as a visual reference.
Scope: desktop and mobile catalog only. Experimental concept; no application code changes.
Reference: .codex/screenshots/2026-10-13/01-catalog.png

## Desktop

Use case: ui-mockup. Generate a high-fidelity realistic UI design screenshot for the existing Russian educational platform «Учебная полка». This is a visual concept only. The attached current catalog screenshot is a reference for content, information density, book/document/video covers, restrained design language and palette, NOT an image to copy unchanged. Explore the navigation arrangement in the brief while retaining a dense reading/search catalog rather than large author-dashboard cards.
Palette MUST use the app's existing neutral dark theme: page #101112, surfaces #171819, white text #f2f2f2, secondary text #989ca3, thin borders #303236, hover #202225, blue accent #4397f7. No navy backgrounds, no gradients, no glass effects, no dramatic shadows. Simple polished Arimo/Arial-like sans-serif, clear Russian text. Rounded controls around 8px. Consistent readable compact typography, professional editorial information hierarchy. No human avatar or portrait. Account is a simple outlined user icon / text. No fake browser chrome, watermarks or presentation captions.
The global header is shared by the public catalog and personal workspace, showing the blue book mark, «Учебная полка», a small «Каталог» entry, a theme toggle, and account access. There must be only ONE prominent text search input in the catalog content, not a duplicate search input in the global header. «Дисциплины» and «Подборки» belong to the local public-area tabs, not repeated as global navigation.
Content in Russian, retain real teaching-library character: title «Каталог материалов», subtitle «Найдено 12 материалов». Local tabs «Материалы» (selected), «Дисциплины», «Подборки». Main search «Поиск по названию, теме или автору…». Sort «Сначала новые». Material examples: «Основы реляционных баз данных» (Книга, Иван Иванов, Базы данных · 2 курс, tags SQL / Базы данных); «Проектирование базы данных» (Статья); «Транзакции и уровни изоляции» (Видео, duration 21:20); «Запросы SQL: практические примеры» (Лекция); «Основы программирования на Rust» (Статья). Every row has a small book/document/video thumbnail, type label, title, author, discipline, concise description and muted tags. Separate rows using subtle horizontal rules; do not turn the catalog into giant standalone dashboard cards. A bookmark action may sit on the right; there are no author workflow statuses such as Draft or Pending in this public catalog. Use recognizable crisp outline icons and no lorem ipsum or random English. Keep every control and title clear, aligned and uncut.
DESKTOP VERSION ONLY. Landscape canvas about 1440×1024. Entire screen, one composition, no phone beside it. Slim global header across the entire width, approximately 64px tall. Under it a single left context sidebar 260px wide is exclusively for catalog filters, NOT a second personal navigation sidebar. Sidebar title «Фильтры», reset «Сбросить», groups «Тип материала» (Лекции, Книги, Статьи, Видео), «Дисциплина» (Базы данных, Программирование, Компьютерные сети), «Преподаватель», «Курс», «Год». Main area starts to the right with roomy heading and local tabs directly below. Then one large search, sort and a subdued «Включить архивные» checkbox. Fit FIVE compact horizontal material rows, with covers roughly 70×90 px, showing enough description to understand each item, aligned metadata and small bookmark icons. Footer «Показаны 1–5 из 12 материалов» and small page numbers 1 2 3 with arrows. Blue active local tab and otherwise calm neutral UI. Match the current catalog's useful list density while making the shared header and local tabs feel connected to the new personal area. Do not add sidebar statistics, personal-area menu, marketing hero, illustrations outside thumbnails, or two sidebars.
