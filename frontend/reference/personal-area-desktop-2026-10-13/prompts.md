# Desktop personal area concepts

Built-in image_gen. Experimental design only, no application code changes. Shared global header and personal navigation; identity panel only on profile, full workspace on publications.

## Profile

Use case: ui-mockup. Generate ONE production-quality desktop UI concept for the Russian educational platform «Учебная полка», a private signed-in PERSONAL ACCOUNT AREA. Landscape approximately1440×1024. This is a visual reference only, not an implementation. Input image1 is a loose reference for profile composition; critique and simplify it rather than copy it. Input image2 is the existing application's target dark color/typography family.
Palette MUST use current global theme: #101112 background, #171819 surfaces, #f2f2f2 text, #989ca3 muted text, #303236 borders, #4397f7 blue accents. Clear Arimo/Arial-like font, refined calm flat UI,8px controls, restrained separators and spacious readable hierarchy. No navy/purple recoloring, gradients, glows, wallpaper, cards inside multiple cards, needless shadows. NO AVATAR, NO PHOTO, NO HUMAN PORTRAIT, NO INITIALS CIRCLE. Account can use a small outline user icon.
Both proposed desktop screens share EXACTLY the same top two navigation levels: 64px global header with blue book logo and «Учебная полка» left, compact «Каталог» link, at right theme toggle, outline user icon and «Иван Иванов» with chevron. No notifications bell, no Community, no duplicate global big navigation, no header search on these personal pages. Directly below header, one horizontal PERSONAL AREA navigation strip across the content width: «Мой профиль», «Моя библиотека», «Мои публикации», «Настройки». Blue underline for selected entry; other entries neutral. It is the ONLY primary personal navigation: do not repeat the same items as left quick actions. No giant enclosing card around the entire page. Generous32px outside margins. All Russian text clean, legible and aligned. No browser chrome, device frame, watermark, explanatory presentation text, donation, subscriptions, follows, rewards, interests tags or social network fields.
PROFILE STATE. Select «Мой профиль» in the shared personal navigation. Below strip: title «Мой профиль» and muted subtitle «Личная информация и данные об обучении»; ONE outline action «Редактировать профиль» with pencil at upper right. No separate edit buttons within every section.
Page content is two columns: a COMPACT left identity panel about280px wide, and much wider main content. The left panel is a text-first identity summary, height roughly250–320px, not a tall full-height side navigation: «Иван Иванов», small «Студент» badge, short biography «Изучаю программирование и базы данных. Интересуюсь веб-разработкой и алгоритмами.» Subtle little label «Личный кабинет». Nothing else: no avatar, no institute/course/group repetition, no counters or quick-action lists. Leave meaningful breathing room beneath the compact identity panel.
Wide right area contains distinct meaningful sections with plain headings and subtle separating rules, not dense nested card outlines. «Личные данные»: aligned rows «Email» / «student@example.com», «Курс» / «2 курс», «Группа» / «ИС-24». Use subtle outline email/graduation/group icons if useful. Then «Мои учреждения»: full-width row «Учебный колледж», secondary «Студент», neutral check and «Членство подтверждено», plus a calm «Найти учреждение» link. This is private own-profile data, not a public author profile. A last small utility section «Безопасность аккаунта» with concise text «Пароль и управление сессиями доступны в настройках» and one quiet text link «Открыть настройки →». No redundant name/biography in main panel. Purposeful modest content density; avoid filling blank space with invented features. Profile should feel clear and reassuring, with main data and controls easy to locate. Make it look polished through proportions, alignment and typography, not decorative imagery.
