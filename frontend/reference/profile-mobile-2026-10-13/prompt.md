# Mobile profile reference

Built-in image_gen. Experimental concept only; application code unchanged.

Use case: ui-mockup. Generate ONE realistic high-fidelity mobile PROFILE screen for the signed-in user of the Russian educational platform «Учебная полка». This is a new visual reference only; preserve the exact visual family of the attached mobile personal-home concept, but compose an appropriate profile/account hub. Portrait about 1024×2208 representing 390×844 CSS px. App content only, no phone frame, browser chrome, OS status bar, device buttons, watermark or presentation caption.
Existing app palette: background#101112, surfaces#171819, primary text#f2f2f2, secondary#989ca3, borders#303236, blue accent#4397f7. Calm flat neutral UI, readable Arimo/Arial-like sans serif, restrained thin dividers and8px control radii. No purple/navy redesign, no gradients, dramatic shadows or glows. NO AVATAR, NO PORTRAIT, NO PHOTO, NO INITIALS CIRCLE. A small generic outline user icon is allowed in navigation only.
Consistent compact top header: blue book mark and «Учебная полка» on left, existing theme toggle on right. No duplicate account icon in the header on this profile screen.
Main heading «Мой профиль» around28–30 CSS px, concise muted subtitle «Личная информация и настройки». Then a clean identity block with text «Иван Иванов», small neutral pill «Студент», short biography «Изучаю программирование и базы данных.» and an outlined button with pencil icon «Изменить профиль». Identity is typography, NOT avatar-centered.
Below a compact information section «Личная информация» with elegantly aligned label/value pairs «Email» / «student@example.com», «Курс» / «2 курс», «Группа» / «ИС-24». Show one clear section «Мои учреждения»: an understated row «Учебный колледж», muted subtitle «Подтверждённое членство · Студент», optional small neutral outlined check icon and a trailing chevron. Keep personal data, education and institution separate but do not put every field in a nested card.
Profile also acts as the entry to account functions REMOVED from the new bottom navigation. Show a compact list of actual access rows with closest matching outline icons at left and chevrons at right: «Мои публикации» with muted subtitle «Материалы, черновики и версии»; «Настройки» with muted subtitle «Внешний вид, пароль и сессии». Do not duplicate «Моя библиотека» as a large shortcut since it already has a bottom tab. Optionally a discreet «Выйти из аккаунта» outlined text action near bottom, secondary emphasis and NO huge red block.
Fixed opaque bottom navigation EXACTLY the same order and structure as attached home concept: «Каталог» with outline book icon, «Главная» with outline house, «Библиотека» with bookmark/books, «Профиль» with outline person. THIS TIME only «Профиль» is selected in blue; all other entries neutral secondary. There must not be a fifth Settings tab or Publications tab. Adequate bottom content padding so logout is visible above the navigation. Keep the entire profile's primary content comfortably visible in one viewport, large enough touch targets, coherent margins16–20px, clear density. No material thumbnails or giant hero needed here. No invented social metrics, follower counts, notifications, achievements, subscription upsells, analytics charts or progress percentages. All Russian text legible and naturally aligned.
