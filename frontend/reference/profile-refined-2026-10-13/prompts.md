# Refined profile concept

Built-in image_gen. Concept only; no application code changes. Two states: default profile and open account bottom sheet.

## Profile

Use case: ui-mockup. Create a refined Russian mobile PROFILE / ACCOUNT HUB for the educational platform «Учебная полка». This is a new experimental image reference, not implemented functionality. Portrait about1024×2208 representing390×844CSS px. Single phone screen only, no presentation board or OS/device/browser chrome.
Input images1 and2 show another service's profile and bottom-sheet menu. They are ONLY loose interaction inspirations. DO NOT clone their visual design, background photo, avatar, composition, fake notifications, social features or financial functions. Input image3 is our existing brand family: match neutral dark surfaces, crisp blue accents and educational identity. Our palette: #101112 page, #171819 panels, #f2f2f2 text, #989ca3 muted text, #303236 thin borders, #4397f7 accent. Flat polished UI, readable Arimo/Arial-like typography, balanced spacing, purposeful sections, 8–12px radii. No neon, gradients, cinematic wallpaper, noisy backgrounds or gratuitous panels.
NO avatar, portrait, initials circle or background image. NO donations, wallet, currencies, balance, paid membership, subscriptions, rewards, badges, achievements, followers, karma, comments, ratings or invented inbox notifications. No decorative hero scene. Only plausible current educational-app functions.
Underlying PROFILE screen: compact header with book mark and «Учебная полка», theme toggle; heading «Профиль» and a small three-dots button aligned right named «Меню». Text-first identity block «Иван Иванов», a modest «Студент» pill, concise biography «Изучаю программирование и базы данных.», text action «Изменить профиль» with pencil icon. Compact educational metadata side by side «Курс — 2» and «Группа — ИС-24». Section «Мои учреждения» containing «Учебный колледж», subtitle «Студент · Членство подтверждено», restrained outline check icon and trailing chevron. Section «Моя работа» with two tidy navigation rows: «Мои публикации» / «Материалы и черновики», and «Мои подборки» / «Учебные маршруты». These are entry points, NOT statistical dashboard cards. A quiet final «Настройки» navigation row with subtitle «Тема, пароль и сессии». Settings and publications live INSIDE profile, not extra bottom tabs. Do not duplicate a big library shortcut since library has its own bottom tab.
Persistent bottom navigation EXACTLY four items in this order: «Каталог», «Главная», «Библиотека», «Профиль»; only PROFILE selected blue. Consistent outline book/home/bookmark/person icons, no avatar as tab icon. Opaque neutral bar, no extra OS home indicator, generous safe content space. User hierarchy should feel more elegant and compact than the earlier stacked-form profile, with important personal information near top and secondary actions below. Use legible exact Russian text and honest restrained content.
STATE: clean default profile, all main sections visible. Show the three-dots menu trigger but the menu is CLOSED. Entire useful profile fits within the single viewport. Make a distinct thoughtfully designed profile, not a copy of the supplied reading-site profile.
